このメモには受診者の氏名・受付番号・個別の検査値は入れていない（件数と仕組みだけ）。前回のメモ（`CODEX相談メモ_石屋判定補正.md`）の続き。

## 1. 前回からの変化

前回の指摘（血糖の漏れ、データ提出）を受けて、方針を変えた。

- 結果票だけでなく、協会けんぽへのデータも出すことになった。協会判定・保健指導レベルが自動判定でしか計算されないので、**3 日分（199 人）とも自動判定をかけ直した**。設定は、通常判定・判定強制実行・総合所見(編集)にコピー。
- 自動判定の前に、服薬歴（問診 084001〜084003 =「はい」）から既往歴 `T_KIOU` に 高血圧 / 糖尿病 / 高脂血症（治療 5 = 薬剤治療中）を入れた（70 人、117 件）。健診ナビは既往歴と `T_KIOU_HANTEI` から、血圧 600150・糖代謝 600340・脂質代謝 600320 を J（治療中）にする。ユーザー決定：服薬中は J にする。J の病気の「要精検」などの文は「治療を継続してください」に変える。
- ユーザー判断：判定は院内基準（健診ナビの基準）でよい。採血時間は全員空腹扱い。眼底所見は文字のまま。

## 3. 意見がほしい点

1. **J と総合判定**: 健診ナビは J をいちばん重く扱う。そのため、腎機能や脂質が F（要精検）でも、総合判定が J「治療中」になる人がいる（他団体も同じ動き）。結果票の総合判定が「治療中」で、医師指示事項に「精密検査の必要があります」が並ぶ。これで受診者が誤解しないか。総合判定(編集) は J のままでよいか。
2. **J の人に残した文**: 糖代謝が J の人でも「【尿糖】陽性です。精密検査の必要があります。」は残した（尿糖は糖代謝のくくりに入るが、治療継続の対象かは決めていない）。消すべきか。
3. **comment_pack で結果CD を動かした件**: 自動判定の文には結果CD（例 `600150HC`、`068676LC`、`001217HC`）が付いている。枠を詰めるとき、文章と一緒に結果CD も上の枠へ動かした。結果CD が枠の番号（11001 など）に意味を持つ可能性や、次の自動判定・データ出力で困る可能性はあるか。
4. **10000 と 11000 が違う人（9 人）**: 結果票は 11000 を印字する。協会けんぽの XML などのデータ出力が、10000 と 11000 のどちらを使うか分からない。11000 だけ直して 10000 を自動判定のまま残したのは正しいか。
5. **眼底の「判定不能」→ E（要再検）**: 総合判定を E に上げた人がいる（1 人）。眼底の撮り直しだけで総合判定を要再検にするのは、一般的な運用か。
6. **胸部X線 F なのに「経過観察」の文**: 胸部X線が F の 5 人で、手入力の文（経過観察）を「精密検査の必要があります」に差し替えた。手入力の文を機械的に上書きするのは危なくないか。
7. **重複の見分け方**: 同じ種類かどうかを文字で見ている（例 腎機能 = 腎機能|ｅＧＦＲ|eGFR、糖 = 糖代謝|糖尿病、胸部 = 胸部、胃 = 胃）。「胃」や「胸部」は、ほかの文に当たる心配はないか。ほかに抜けている組み合わせはあるか。
8. **元に戻すときの照合**: kukuri_comment_undo は「今の文章 = 記録の後の文章」のときだけ戻す。文章の前後の空白は LTRIM/RTRIM で落として比べている。comment_pack の記録は空白を落とさずに書いているので、戻せない枠が出る可能性がある。直すべきか。
9. **そのほか**: 自動判定をかけ直したあと、ツールで補正する流れ全体で、ほかに漏れそうなところ。とくにデータ提出（保健指導レベル・メタボ判定・協会判定）で、補正が反映されていない項目はないか。
