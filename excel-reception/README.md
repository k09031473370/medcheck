# excel-reception

インフルエンザ予防接種（元は健康診断）の受付用 Excel マクロアプリ一式。

| ファイル | 用途 |
|---|---|
| `インフル予防接種受付_テンプレート.xlsm` | 名簿・受付データを空にしたテンプレート。これをコピーして各事業所・各日のファイルを作る |
| `事務員向け_各日ファイル作成手順.md` | 事務員が名簿を受け取ってから現場用ファイルを作るまでの手順書 |
| `tools/make_template.py` | 使用済みファイル（去年の 1128 ファイル）からテンプレートを再生成したスクリプト。VBA を壊さないよう OOXML を直接編集している |

テンプレートは Microsoft 365 / Excel 2021 以降が前提（FILTER, SORTBY, XLOOKUP を使用）。
