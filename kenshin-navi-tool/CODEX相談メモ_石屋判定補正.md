# 相談メモ: 健診ナビの判定を自動判定なしで補正した件（漏れの確認のお願い）

このメモには受診者の氏名・受付番号・個別の検査値は入れていない（件数と仕組みだけ）。

## 1. 前提

- 健診システム「健診ナビ」（SQL Server。結果は `T_KENSA` に 1 人 × 項目 1 行: `KEKKA` 値 / `KEKKA_CD` コード / `HANTEI_KIGO` 判定 / `HL` 印）。
- 判定は 8 段階: A 異常なし / B 心配なし / C 要注意 / D 要観察 / E 要再検 / F 要精検 / G 要治療 / J 治療中。
- こちらで作った PowerShell ツールが DB に直接書く（プレビュー → y → 1 人ずつバックアップ → トランザクション + アプリロック → 取り消し用 CSV）。
- 守っている制約: 健診ナビ本体・マスタ（基準値・コース・所見マスタ）は変えない。枠（T_KENSA の行）はツールで作らない。
- 対象: 1 つの団体の 3 日分（9/3 58 人、9/9 90 人、9/10 51 人、計 199 人）。結果票は帳票303。

## 2. なぜ補正が必要になったか

1. 外注検査の HbA1c・血小板・eGFR を後から取り込んだ。健診ナビにはこの 3 項目の基準値が無い（または後から枠を足した人は自動判定に入っていない）ので、項目の判定・くくり判定（糖代謝・血液一般・腎機能）・総合判定に反映されていなかった。
2. 中性脂肪は「中性脂肪(未判別) R06-0002」で入る。自動判定が採血時間（食後 10 時間以上 / 3.5〜10 時間 / 3.5 時間未満）を見て空腹時中性脂肪 068702 / 随時中性脂肪 R06-0003 に写してから判定する。9/9・9/10 は自動判定のあとに採血時間を入れたので、写っておらず判定が無い。血糖も同じで、血糖(未判別) 068682 が空腹時血糖 H30-0011 等に写っていない。
3. 眼底の所見は業者ファイルの文字（「視神経乳頭陥凹の拡大」等）で入れた。所見マスタのコードではないので自動判定は判定を付けず、【判定】眼底 600060 は所見のある人も A のままだった。業者ファイルの眼底の総合判定（A〜G）は取り込んでいなかった。
4. 結果票は血糖を血糖(未判別)、中性脂肪を中性脂肪(未判別)から印字する（帳票の対応表で確認）。なので結果票には振り分けは効かず、未判別の判定・H 印、くくり判定、総合判定が効く。
5. 自動判定をかけ直すと、取り込んだ判定・手で付けた判定・コメントが消える可能性があるので、かけ直さずに補正することにした。

## 3. やったこと

| 手順 | 内容 |
|---|---|
| 判定取込 | HbA1c・血小板・eGFR の判定を外注の値から付けて項目の判定欄に（199 人） |
| 眼底取込 | 業者の眼底判定を【判定】眼底 600060 に。A→A、B→B、C 経過観察→D、D 要精検→F。F 要継続治療・G 判定不能は未対応（先生に確認中） |
| くくり補正 | 項目の判定の方が重いときだけ、くくり判定を上げる（糖代謝 ← HbA1c、血液一般 ← 血小板、腎機能 ← eGFR、脂質代謝 ← 中性脂肪）。総合判定はこれらと眼底の最も重い判定まで上げる。軽くはしない |
| 中性脂肪 | 未判別に判定が無い人は空腹時の基準で判定と H/L 印を付ける（29 以下 F(L)、30〜149 A、150〜299 B、300〜499 D、500〜700 F、701 以上 G）。ユーザー判断で 9/9 以降は全員空腹扱い |
| コメント | 総合判定のコメント欄（9 枠）に、HbA1c・eGFR・中性脂肪・眼底が D/F の人へ定型文を足す。同じ種類の文が既にあれば足さない（文字で判定）。F なのに軽い文しか無ければ差し替える |

## 4. こちらで気になっている点（意見がほしい）

1. **データ送信（保険者・協会けんぽ向け XML 等）**: 9/9・9/10 は血糖・中性脂肪が空腹時/随時の項目に写っていない。結果票は未判別から印字するので問題ないが、送信データが空腹時血糖・空腹時中性脂肪の項目を使うなら、9/9・9/10 の約 140 人は血糖と中性脂肪が欠ける。自動判定のかけ直し以外に安全な直し方はあるか。かけ直すなら、そのあと上の補正ツールを全部流し直せば元に戻るか。
2. **【協会判定】眼底指導区分 610100** にも枠がある（168 人）。眼底の判定を 600060 だけ直したが、協会判定側も直す必要があるか。同様に、糖代謝・脂質・腎機能の協会判定や、特定健診の階層化（保健指導レベル）が古い値のまま計算されていないか。
3. **H/L 印**: 中性脂肪にだけ H/L 印を付けた。HbA1c・eGFR・血小板の H/L 印は値の取込時に付いているか確認していない。結果票に印が出る項目なら抜けになる。
4. **中性脂肪の空腹扱い**: 9/9・9/10 で業者ファイル上は食後 3.5 時間や 1 時間の人が 20 人余りいたが、全員空腹の基準で判定した（ユーザー判断）。随時の基準（175 以上で異常）にしなくてよいか、医学的に見て大きな問題はあるか。
5. **自動判定の再実行リスク**: 事務員が誤って 9/3・9/9 に自動判定をかけると補正が消える。取り消し用 CSV を使って「今の DB が補正後のままか」を見る点検スクリプトを作っておくべきか。
6. **コメントの重複判定**: 同じ種類の文があるかを文字（「糖代謝|糖尿病」「腎機能」「中性脂肪」「眼底」）で見ている。最初は「糖」だけで見ていて【尿糖】の文を誤認した。ほかに誤認しそうな組み合わせはあるか。
7. **くくり判定の対応の過不足**: HbA1c→糖代謝、血小板→血液一般、eGFR→腎機能、中性脂肪→脂質代謝 としたが、健診ナビの本来の対応（たとえば HbA1c が糖代謝以外のくくりにも効く、eGFR が腎機能以外に効く）を見落としていないか。
8. **そのほか**: この流れ（自動判定のあと採血時間・外注結果・業者判定を足し、自動判定をかけずに直す）で、ほかに漏れそうなところ。
