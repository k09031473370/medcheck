受診表作成アプリ　使い方
　　マイクロンメモリジャパン 2026年10月 健診 専用
=====================================

※ このアプリは今回の健診専用です。他社の健診には使わないでください
　 （斜線のルールを今回の3コース用に変えてあります）。
　 他社の分は、元の「受診表作成アプリ_事務員用」を使ってください。

■ 手順
 1. 予約名簿のシート（予約取込入力例 (3)）を
    「CSV UTF-8」で data.csv という名前で保存する
 2. data.csv を main.exe と同じフォルダに置く
 3. main.exe をダブルクリックする
 4. 同じフォルダに Complete_Health_Check.pdf ができる（1人1ページ・A3横）
 5. 画面に出るコース別の人数と「胃部に斜線を入れた人」の数を確認する
 6. PDF を開いて印刷する

■ 名簿の加工は不要です
 ・列は「見出しの名前」で読んでいます。33列でも35列でも、
   年齢や個人コードの列が入っていても、そのままで正しく読みます。
 ・1行目に集計の行（0, 296, 296 …）が入っていても、
   自動で見出しの行（氏名 がある行）をさがすので消さなくて大丈夫です。
 ・使う列： 氏名 / 氏名カナ / 性別 / 生年月日 / 保険証記号 / 保険証番号
           事業所名 / コース名 / 予約日 / オプション検査1～10

■ 斜線のルール（今回の健診）
    コース                      胃部           採血   心電図
    人間ドックD１コース            検査あり         あり    あり
    一般健診A2コース              オプション次第     あり    あり
    生活習慣病予防健診Bコース       オプション次第     あり    あり

 ・胃部は「オプション検査」の欄に “胃部X線検査” が入っている人だけ検査ありにし、
   入っていない人は胃部の枠に斜線を引きます。
 ・胸部は全員検査ありです。
 ・コース名が空欄のときは斜線なし（全検査あり）になります。

■ 注意
 ・年度末年齢は 2027年3月31日 時点で計算しています。
 ・生年月日や性別が空欄でも、記入用のガイド（　/　/　、男・女）が
   印字されるので手書きで対応できます。
 ・main.exe を作り直すときは build.bat を実行してください
   （Python と pyinstaller・reportlab が要ります）。
   Python が入っていれば python main.py でもそのまま動きます。

■ うまくいかないとき
 ・「data.csv が見つかりません」→ main.exe と data.csv を同じフォルダに置く
 ・文字化けする → data.csv を Excel で開き「CSV UTF-8」で保存し直す
 ・PDF が上書きできない → 先に Complete_Health_Check.pdf を閉じる
 ・人数が名簿と合わない → 氏名も氏名カナも空の行は飛ばしています
