# 健診結果 取込ツール 運用マニュアル

芝浦健診クリニック / KENSHIN navi 11 — 第1版 2026/07/27

## 1. このマニュアルについて

巡回健診のExcelフォームと、心電計の結果CSVを、健診ナビへ自動で取り込むツールの使い方です。
ツール一式は `C:\Users\User\Documents\excel_tools` にあります。

- 健診ナビ本体のプログラムは一切変更していません(結果を画面手入力と同じ形式で登録するだけ)
- 取込は「プレビュー(確認)」と「書込」の2段階。書込しない限りデータは変わりません
- 書込のたびに、その人の書込前データが `C:\Users\User\Documents\excel_tools\backup` に自動保存されます

## 2. 大原則(必ず守る)

1. **必ず「プレビュー」で内容を確認してから「書込」する**
2. エラーが表示されたまま強行しない(意味と対処は第6章)
3. **書込後は健診ナビで「自動判定」を実行する**(BMI・判定はナビ側で計算)

## 3. 健診フォーム(Excel)の取込 〈画面操作〉

使うもの: `form_import_gui.ps1`(画面版)。ExcelのままでOK(CSV保存は不要)。

1. ツールを起動:
   `powershell -ExecutionPolicy Bypass -File C:\Users\User\Documents\excel_tools\form_import_gui.ps1`
2. 「参照...」でフォームのExcelファイルを選ぶ
3. 受付番号(例: 4001)と受診日(例: 2026/07/02)を入力。全員まとめてなら受付番号を空欄に
4. 「3. プレビュー」→ 表の「状態」列がすべて OK であることを確認
5. 「4. 書込実行」→ 確認ダイアログ「はい」
6. 健診ナビで対象者を開き「自動判定」→ 値と判定を確認

## 4. 心電図結果CSVの取込 〈コマンド〉

使うもの: `ecg_import.ps1`。心電計の結果CSV(ecgresult〜.csv)が対象。
ID列=その日の受付番号、検査日列=受診日として本人を特定します。

1. 心電計から結果CSVを保存(例: デスクトップ)
2. プレビュー:
   `powershell -ExecutionPolicy Bypass -File C:\Users\User\Documents\excel_tools\ecg_import.ps1 -Csv "C:\...\ecgresult〜.csv"`
3. 各IDの「書込所見」「判定」を確認し、問題なければ末尾に `-Commit` を付けて書込
4. 健診ナビで「自動判定」

補足:
- 1人だけ: `-Only 13` のようにIDを付ける
- 所見ゼロ+判定Aの人には自動で「異常なし」が登録される
- 判定(A/B/C12等)も心電図判定の枠に書き込まれる(`form\ecg_items.csv` のHANTEI行を設定した場合)

## 5. 書込後の確認

1. 健診ナビの結果入力画面で対象者を開く
2. 取り込んだ値・所見の目視確認
3. 「自動判定」実行 → BMI・各判定・総合判定を確認
4. 東振協などの出力処理へ

## 6. エラーの意味と対処

| 表示 | 意味 | 対処 |
|---|---|---|
| 枠なし | その人のコースにその検査項目が無い | コース設定を確認。対象外なら無視でOK |
| 変換不可 | 値の表記がルール外(例: 尿「3±」) | 値を直すか `form\value_map.csv` に変換を追加 |
| 所見未登録 | 所見文が所見マスタに無い | マスタの表記に合わせる。恒常的なら変換表へ |
| コード未対応 | 心電図の装置コードが変換表に無い | `form\ecg_code_map.csv` にKEKKA_CDを追記 |
| 受診者が見つからない | 受付番号・受診日が不一致 | 受診日(YYYY/MM/DD)と受付番号を確認 |
| 接続エラー | サーバー(KNSV)に繋がらない | サーバー起動確認。README.md参照 |

## 7. 初期設定(初回のみ・設定担当者向け)

| ファイル | 設定する内容 |
|---|---|
| `form\mapping.csv` | フォーム列番号(Col)とKOMOKU_CD。`-Inspect` と `-DumpItems` で確認 |
| `form\ecg_items.csv` | 心電図所見1〜5のKOMOKU_CD |
| `form\ecg_code_map.csv` | 装置コード(B01等)→KEKKA_CD。`-DumpSyoken ZK011` と `-ListCodes` で確認 |
| `form\value_map.csv` | 尿定性・聴力の表記ゆれ変換(通常は変更不要) |

## 8. 元に戻したいとき

- `backup\T_KENSA_<番号>_<日時>.csv` に書込前の全データが残っている
- 少量なら健診ナビの画面から手修正が最も安全
- 大量に戻す場合はバックアップCSVを見ながら復元(設定担当者に相談)

## 9. 禁止事項・注意

- **江東微研(城南/城西)のコード変換マスタ、`\\KNSV\KenshinNavi\CSV\検査センター.csv` は変更しない**
- プレビューせずに `-Commit` しない。`-Force` の常用禁止
- 対応表CSVはメモ帳/VSCodeで編集(Excelだと `084001` の先頭ゼロが消える)
- 取込中は健診ナビでその受診者の結果入力画面を開かない
