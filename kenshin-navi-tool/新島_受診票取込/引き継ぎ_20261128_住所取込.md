## 3. 道具を作るときの決まり

- `.ps1` は UTF-8（BOM つき）＋ CRLF。`.bat` は ASCII ＋ CRLF で、中に日本語を書かない。`form/*.csv` は UTF-8（BOM つき）。
- PowerShell 5.1 で動かす。変数名は大文字と小文字を区別しないので、`$FB` と `$fb` のような重なりを作らない。
- 共通の関数は `form_import.ps1` から切り出して借りる（`kiou_v5.ps1` の先頭の `Get-Part` と `Invoke-Expression` の使い方が見本）。Excel の読み込みは `xlsx_read.ps1`。
- 調べる道具は `checkNNN.ps1` ＋ `checkNNN.bat` の組で、`db_tool.ps1 -Sql … -MaxRows …` を呼び、`r_checkNNN.txt` に出してメモ帳で開く（見本は `check122.ps1`、`check123.ps1`）。`db_tool.ps1` は 30 秒で時間切れになる。
- こちらでは PowerShell を動かせない。かっこの対応と変数名の重なりは、作ったあとに機械的に確かめる。
