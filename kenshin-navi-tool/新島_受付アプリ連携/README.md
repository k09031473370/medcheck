# 新島の受診予定者を受付アプリに事前登録する — 下調べと見本

作成 2026/11/07。ここにあるファイルはすべて **ダミーデータ** です（実在の受診者は入っていません）。

## 1. 健診ナビの画面から出せるか

**まだ確かめられていません。** これまでの作業で分かっている健診ナビの画面は次のとおりで、
どれも「受診予定者の名簿を CSV / Excel で出す」ものではありませんでした。

| 画面 | できること | 名簿の出力 |
|---|---|---|
| 予約データ取込 | Excel から予約を**取り込む** | ×（入れる側） |
| 予約画面 | 氏名で検索・予約取消・受付内容変更 | 不明（出力ボタンを見ていない） |
| 健康診断結果報告書 | 受診日・コースで絞って結果票を Excel / PDF で出す | ×（結果票であって名簿ではない） |

健診ナビの画面で、次を確かめてください（見るだけ。何も登録しない）。

1. 予約画面（予約一覧）に「Excel」「CSV」「出力」「印刷」のボタンがあるか
2. 帳票・印刷のメニューに「受診者名簿」「予約者一覧」「受付名簿」のような帳票があるか
3. あれば、受診日と事業所で絞れるか、出てくる列（番号・氏名・フリガナ・生年月日・性別・コース）は何か

画面から出せれば、それがいちばん簡単で安全です。出せなければ 2 の方法にします。

## 2. 画面から出せない場合: データベースを読むだけで一覧を作る

**同じやり方を「受診票データ作成.ps1」で実際に使っています**（受診日の受診者の氏名・フリガナ・事業所・コースを読んで受診票を作る。読むだけ）。

- SELECT（読む）だけ。予約・個人情報の追加・変更・削除はしない
- 対象: 事業所名に「新島」「式根島」が入る事業所 × 受診日の期間 × 取消を除く
- 出力先は院内の PC のフォルダだけ（excel_tools\out）。メールやクラウドには送らない
- できたファイルは要配慮個人情報なので、受付アプリに取り込んだら消す

## 3. 項目と健診ナビの置き場所

| 見本の列 | 健診ナビ | メモ |
|---|---|---|
| 受診者番号 | `T_KENSIN.PK_SEQ`（予約の番号） | **おすすめ。** 予約 1 件に 1 つ。当日の受付番号を健診ナビに戻すとき、氏名で照合しなくて済む（福生では氏名照合だった） |
| 個人ID | `T_KOJIN1.KOJIN_ID` | 人ごとの番号。年をまたいでも同じ |
| 受診日 | `T_KENSIN.D_KENSIN` | |
| 時間帯・順番 | 未確認 | 健診ナビに持っているか check118 の 7 で探す。無ければ受付アプリ側で入れる |
| 事業所コード・事業所名 | `T_KENSIN.DANTAI_CD1` → `M_DANTAI.MEISYO1` | |
| 氏名 | `T_KOJIN1.KANJI_SIMEI` | |
| フリガナ | `T_KOJIN1.KANA_SIMEI` | 健診ナビは**半角カナ**のことがある（例 ﾐﾎﾝ ｲﾁﾛｳ）。受付アプリが全角を使うなら変換して出す |
| 性別 | `T_KOJIN1.SEIBETU` | 1 = 男 / 2 = 女 |
| 生年月日・年齢 | `T_KOJIN1.D_SEINEN` | 年齢は受診日時点で計算 |
| コースコード・コース名 | `T_KENSIN.COURSE_CD` → `T_COURSE1.MEISYO` | |
| オプション | `T_RYOUKIN` の `OP〜` の行 → `T_KOMOKU.MEISYO1` | 「・」でつなぐ（JSON では配列） |
| 受付番号 | `T_KENSIN.UKE_NO_KENSA` | 事前登録の時点では空のことが多い |
| 住民番号等 | `T_KOJIN1.KOJIN_NO` | 新島村の巡回で使われていた欄（2026/08 の調べ）。要るかどうか確認 |
| 取消 | `T_KENSIN.F_TORIKESI` | 取消は出さない予定（列は検算用） |

## 5. 決めてほしいこと

1. 受付アプリが読める形式（CSV・Excel・JSON のどれか、列名や並び）。見本の列名は仮です
2. 受診者番号を **予約の番号（PK_SEQ）** にしてよいか
3. フリガナを全角にするか半角のままか、生年月日の書き方（2026/11/20 か 2026-11-20 か）
4. 時間帯・順番を受付アプリに入れたいか（健診ナビに無ければ受付アプリ側で付ける）
5. 住民番号等（KOJIN_NO）は要るか

これが決まって、check118 で人数と項目の埋まり方を確かめてから、実際の一覧を出す道具を作ります。
