# 新島の受診票（スキャン）を健診ナビに取り込む — これまでの取込方法の調べ

作成 2026/11/07。調査だけ。データの書き込み・実際の取り込みはしていない。

## 1. これまでの取込方法

| 道具 | 使い道 | 実績 |
|---|---|---|
| `start.bat`（画面）／`form_import.ps1` | 1 人 1 行の Excel / CSV を読み、健診ナビの検査の枠（`T_KENSA`）に結果を書く。**受診票の取込はこれ** | 芝浦巡回の AI データ（受診票を読み取ったもの）、当日フォーム、SRL 血液、東振協、リアン、入力画面バックアップ |
| `既往歴取込.ps1` | 既往歴（病名）を `T_KIOU` に入れる | 東振協 |
| `自覚症状取込.ps1` | 自覚症状を `017107A〜J` の枠に詰める | 東振協 |
| `心電図取込.bat`（ecg_import） | 心電図の所見 | |

どのレイアウトかは、1 行目の見出しと列の数で自動で判別する（`form\mapping_*.csv` の `DETECT`）。

## 2. 受診票に使うファイルの形（推奨）

**`健診結果_取込フォーマット_氏名つき.xlsx`（49 列）** をひな形にする。対応表は `form\mapping_shibaura_ai3.csv`。

- 形式: **.xlsx のまま読める**（CSV なら Shift_JIS が既定）
- 1 行目の見出しと列の順番は変えない（判別に使う）。2 行目の記入例は消す。3 行目から 1 人 1 行
- 単位は書かず数字だけ。測っていない項目は空欄（空欄は書かない）
- 2 枚目のシート「記入要領」に列の一覧がある

| 列 | 見出し | 中身 | 健診ナビの項目 |
|---|---|---|---|
| 1 | 受診日 | 2026/06/15 の形。**全員の行に入れる** | （照合用） |
| 2 | 受付NO | 受付番号 | （照合用） |
| 3〜24 | Q1 服薬歴(血圧) 〜 Q22 保健指導 | 特定健診の問診 22 問。回答の番号（1 = はい / 2 = いいえ など） | 084001〜084021・H30-0061・H30-0062・R06-0004 |
| 25 | 食事時間(空腹) | 1 = 食後10時間以上 | 001282 |
| 26〜28 | 身長・体重・腹囲 | 数字 | 001211・001212・001215 |
| 29〜32 | 最高/最低血圧(初回)・(2回目) | 数字 | 001253〜001256 |
| 33〜36 | 視力(右) 種別・視力(右)・視力(左) 種別・視力(左) | 種別 1 = 裸眼 / 2 = 眼鏡 / 3 = コンタクト（2・3 は矯正の枠に入る） | 067012・067013（裸眼）/ 067018・067019（矯正） |
| 37〜40 | 聴力 右/左 1000Hz・4000Hz | 1 = 所見なし / 2 = 所見あり | 067132〜067135 |
| 41 | 聴力備考 | 健診ナビに枠が無い。入力があったことを知らせるだけ | — |
| 42〜44 | 尿蛋白・尿糖・尿潜血 | 選択肢の番号、または (-) (±) (+) のような表示の文字 | 069206・069207・069211 |
| 45 | 他覚所見1(診察) | 所見コード（1 = 異常なし） | 017101A |
| 46 | 胸部X線所見1 | 所見コード | 077010A |
| 47 | 心電図所見1 | 所見コード（1 = 正常範囲） | 067112A |
| 48 | 氏名(漢字) | 取り違え防止の照合用 | — |
| 49 | 氏名(カナ) | 半角カナ。漢字より先に照合する | — |

選択式（問診・尿・聴力）は、健診ナビの選択肢マスタ（`T_SYOKEN2`）で番号 → 表示の文字・判定に読み替えて書く。番号でも表示の文字（(-) など）でも当たる。所見（診察・胸部X線・心電図）は所見コードで書く。

新島の受診票にこの 49 列に無い欄（自覚症状・既往歴の病名・眼底・胃部など）があれば、
- 対応表（`form\mapping_niijima.csv` など）を 1 本足す（ツールは変えない）
- 既往歴・自覚症状は、専用の道具の入力形式に合わせる

## 3. 受診者の照合キー

1. **受診日 ＋ 受付番号** で予約を 1 件に決める
   - 受付済みなら `T_KANJA_G`（KEN_YMD・KEN_NO）、まだなら `T_KENSIN`（D_KENSIN・UKE_NO_KENSA、取消は除く）
   - 2 件以上見つかったら止まる
2. 見つかった人の **氏名（カナ・漢字）** をファイルの氏名と突き合わせる
   - カナか漢字の**どちらかが一致すれば同じ人**（漢字は旧字体、カナは読み違いがあるため）
   - 両方違えば「氏名が一致しません」で、その人は書かない
3. 受付番号の列が無いファイル（東振協など）は、受診日の中で**カナ → 漢字の順に氏名で探す**。1 人に決まらなければ書かない

**新島で先に確かめること**: 健診ナビの新島の予約に受付番号が入っているか（`check118.bat` の 4「受付番号あり」）。
入っていなければ、取り込む前に受付番号を健診ナビに入れる手順（画面の「受付番号を設定」＝氏名で照合して入れる。これは書き込み）が要る。
住民番号（`T_KOJIN1.KOJIN_NO`）は照合キーには使っていない。

## 4. 取り込める項目と取り込めないもの

- 書けるのは、**予約のときに作られた検査の枠がある項目だけ**。枠が無い項目は「枠なし」と出て書かない（ツールは枠を新しく作らない）
- BMI・判定・総合判定は書かない。取り込んだあと健診ナビの「自動判定」で出す
- 血液は SRL のファイルで別に取り込む

## 5. 実行前の確認方法（書き込まない）

1. **中身だけ見る（データベースにつながない）**: `form_import.ps1 -Csv <ファイル> -Inspect -Only <受付番号>` で、列番号・見出し・値・読み替えた結果を出す
2. **プレビュー**: 画面の「3. プレビュー」（`-Commit` を付けない）。状態を見る
   - OK／枠なし（コースに無い）／受診者が見つかりません（受付番号か受診日が違う）／氏名が一致しません（**必ず確認**）／変換表に無いコード
3. **1 人だけで試す**: `-Only <受付番号>`
4. **その人の枠を見る**: `-Only <受付番号> -KenYmd <受診日> -DumpItems` で、検査の枠と今の値を出す
5. **名簿で絞る**: `-Roster <名簿>` で、名簿に載っている人だけを対象にする
6. **健診ナビでその人の画面を閉じておく**（開いていると止まる）

書き込むときは、書く前に `backup\T_KENSA_<PK_SEQ>_<日時>.csv` に控えを取る。戻すときは `元に戻す.bat`。

## 6. スキャンをデータにするときの注意

- 文字読み取り（OCR・AI）の結果は、そのまま取り込まずに上の 1・2 で確かめる。特に受付番号・受診日・氏名
- 受診日は全員の行に入れる（空の行はエラー）
- 数字の列に単位・全角・余計な文字が入らないようにする
- 読み取れなかった欄は空欄のまま（空欄は書かない）
- スキャン画像・データ化したファイルは要配慮個人情報。院内の PC の中だけで扱い、外のサービスに送らない
