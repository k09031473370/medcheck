# インフルエンザ予防接種 受付ファイル作成手順（事務員向け）

事業所から申込名簿（Excel）を受け取ったら、この手順で **その事業所・その実施日用の受付ファイル** を1つ作ります。
現場のスタッフはそのファイルを開いて、当日の受付をします。

- ルール：**1事業所 × 1実施日 = 1ファイル**（同じ事業所で複数日ある場合は後述）
- 所要時間：慣れれば5分程度
- 必要なもの：Excel（Microsoft 365 または Excel 2021 以降）、テンプレート `インフル予防接種受付_テンプレート.xlsm`、申込名簿

---

## 手順1　テンプレートをコピーして名前を付ける

1. `インフル予防接種受付_テンプレート.xlsm` を **右クリック → コピー → 貼り付け** でコピーします。
   （テンプレート本体は絶対に直接編集しないでください）
2. コピーしたファイルの名前を変えます。

   例：`20261105_KENWOOD.xlsm`　（実施日8桁_事業所名）

3. 拡張子は `.xlsm` のままにします。`.xlsx` にするとボタンが動かなくなります。

## 手順2　ファイルを開いてマクロを有効にする

1. コピーしたファイルを開きます。
2. 上部に黄色い帯で「セキュリティの警告　マクロが無効にされました」と出たら、**「コンテンツの有効化」** を押します。
3. 「表紙」シートが表示されれば OK です。

> 警告が出ず、ボタンを押しても何も起きない場合は、ファイルを閉じて、右クリック → プロパティ → 「許可する」にチェック → 再度開いてください。

## 手順3　会社マスタに事業所名を入れる

1. 「会社マスタ」シートを開きます。
2. B4 セルに事業所名を入力します（例：`KENWOOD`）。
3. 名簿に複数の事業所が混ざっている場合は B5、B6 … と続けて入力します。

> ここに入れた名前が、入力シートの「会社名」プルダウンの選択肢になります。
> 手順4で貼る名簿の会社名と、**文字が完全に一致**している必要があります（全角/半角、スペースも含む）。

## 手順4　申込名簿を「受診者マスタ」に貼り付ける

「受診者マスタ」シートの表（4行目以降）に、申込名簿の内容を **列ごとに** 貼り付けます。
申込名簿の列の並びはテンプレートと違うので、まとめて貼らず、1列ずつ「値のみ貼り付け」します。

| 受診者マスタの列 | 項目 | 貼り付け | 補足 |
|---|---|---|---|
| B | 受付済み | **貼らない** | 当日の受付で自動的に「済」が付く |
| C | 検索キー | **貼らない（数式）** | 消すと入力シートが動かなくなる |
| D | 氏名 | **必ず貼る** | 姓と名の間は全角スペース推奨 |
| E | カナ氏名 | **必ず貼る** | 氏名プルダウンの並び順（カナ順）に使う |
| F | 性別 | あれば貼る | 「男性」「女性」 |
| G | 生年月日 | あれば貼る | |
| H | 健保名 | あれば貼る | |
| I | 会社名 | **必ず貼る** | 手順3で入れた名前と同じ文字にする |
| J | 検診コース | 空欄のまま | 健診用。インフルでは使わない |
| K, L | 正式コース名・年齢 | **貼らない** | 自動列 |
| M | フリー1 | 任意 | 去年は事業所コードを入れていた |
| N | フリー2 | 任意 | 去年は社員番号を入れていた |
| O | フリー3 | 任意 | 去年は受診者番号。入力シートの「フリー3で検索」ボタンで使える |

**貼り付けのやり方**

1. 申込名簿で氏名の列を選択してコピー。
2. 受診者マスタの D4 セルを選んで、**右クリック → 貼り付けのオプション → 「値」（123のアイコン）** で貼り付け。
3. カナ氏名（E列）、会社名（I列）、フリー1〜3（M〜O列）も同じように貼る。
4. 会社名が全員同じなら、I4 に1件入れて、セル右下の■をダブルクリックすると最終行まで一気に埋まります。

**貼り付け後の確認**

- C列（検索キー）に `KENWOOD_山田　太郎` のように「会社名_氏名」が全員分表示されている。
- 表の最終行より下に貼った場合、表（青い枠）が自動で広がっている。広がっていなければ、表の右下の小さな「┘」マークをドラッグして広げる。

## 手順5　実施日のシートを作る

1. 「表紙」シートに戻ります。
2. 右側の **「✨ 日付シート作成」ボタン** を押します。
3. 実施日を **8桁の数字** で入力します（例：2026年11月5日 → `20261105`）。
4. 「作成しました」と出たら OK。シートの一番右に `20261105` という名前のシートができます。

> このシートが無いと、当日の「受付登録」でエラーになります。必ず実施日の分を作ってください。
> 同じ事業所で実施日が2日ある場合は、このボタンを2回押して2枚作ります（1ファイルで2日分を管理できます。受付No.は2日通しで連番になります）。

## 手順6　動作確認

1. 「入力シート」を開きます。
2. 右上の受付No.が `1` になっている（初回はこの番号から採番されます。別の番号から始めたい場合は C3 セルを書き換える）。
3. 「会社名」のプルダウンに手順3で入れた事業所名が出る。
4. 会社名を選ぶと「氏名」のプルダウンに名簿の人がカナ順で出る。
5. 氏名を選ぶと、カナ氏名・フリー1〜3 が自動表示される。
6. 確認が終わったら **「🧹 クリア」ボタン** で入力を消す（確認で「受付登録」は押さないでください。押してしまった場合は、日付シートのその行を削除し、受診者マスタの「済」を消し、入力シートの受付No.を 1 に戻してください）。

## 手順7　保存して現場へ渡す

1. Ctrl + S で保存（形式は `.xlsm` のまま）。
2. 現場で使う PC・共有フォルダにコピーします。
3. OneDrive 上で直接使う場合、同期の遅れでエラーが出ることがあるため、できればローカルにコピーして使ってください。

---

## 当日の受付の流れ（現場スタッフ向けメモ）

1. ファイルを開き「コンテンツの有効化」。
2. 「入力シート」で会社名 → 氏名を選ぶ（または「🔍 フリー3で検索」で番号入力）。
3. **「➕ 受付登録」** を押す → 確認ダイアログで「はい」。
4. 日付シートに1行追加され、入力欄が自動で消え、受付No.が次の番号になる。
5. 同じ人を二度登録しようとすると「既に受付済みです」と警告が出る（通常は「いいえ」）。
6. 便潜血・オプションの欄は健診用なので、空欄のまま登録して構いません。
7. 日付シート上部の「受付人数」で当日の人数が確認できます。

## よくあるトラブル

| 症状 | 原因と対処 |
|---|---|
| ボタンを押しても何も起きない | マクロが無効。手順2を確認。拡張子が `.xlsx` になっていないか確認 |
| 「○月○日のシートが存在しません」 | 実施日のシートが未作成。手順5を実施。入力シートの日付（F2）は今日の日付が自動で入るため、前日にテストする場合は F2 を実施日に手で書き換える |
| 氏名のプルダウンに誰も出ない | 受診者マスタの会社名（I列）と会社マスタの名前が一致していない。または C列の検索キー数式が消えている |
| 氏名プルダウンが「#NAME?」になる | Excel が古い（FILTER / SORTBY 関数が無い）。Microsoft 365 か Excel 2021 以降を使う |
| 受付No.が 1 から始まらない | 動作確認で登録してしまった、または日付シートにデータが残っている。日付シートの行を削除し、C3 を 1 に戻す |
| 「既に受付済み」が誤って出る | 同姓同名が名簿にいる。「はい」で登録を続けるか、備考で区別する |

## 複数事業所・複数日の整理

- 事業所が違う → **ファイルを分ける**（手順1からやり直す）
- 同じ事業所で日が違う → **同じファイルに日付シートを追加**（手順5を日数分）
- ファイル名は `実施日_事業所名.xlsm` で統一すると、あとで探しやすくなります
