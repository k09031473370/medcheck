# 福生商工会 当日の取込手順（午後の部・翌日も同じ）

使うもの: `C:\Users\User\Documents\excel_tools` の `受付結果取込.bat` と `予約取込Excel作成.bat`、健診ナビの「予約データ取込」

---

## 全体の流れ

```
① 受付アプリ → 健診ナビ連携JSON を出す（D: などに保存）
② 受付結果取込.bat に JSON をドラッグ → Y        … もう予約がある人に受付番号
③ 予約取込Excel作成.bat に JSON をドラッグ         … まだ予約が無い人の Excel
④ その Excel を健診ナビの「予約データ取込」にドロップ → 予約登録
⑤ 受付結果取込.bat に JSON をドラッグ → Y        … ④で入れた人に受付番号
⑥ ★のお知らせを健診ナビの画面で対応
⑦ 検体依頼
```

②と⑤は同じ操作。②で入らなかった人を④で登録して、⑤でもう一度入れるだけ。

---

## ② 受付結果取込.bat

1. JSON をドラッグ
2. プレビューを見る
   - 「更新する人」が全部 **受付番号 []→[N]** で、受診日が**今日**になっているか
   - 「見つかりません」の人は③で登録するので、ここでは気にしない
3. **Y**
4. 「読み直し確認: 全部そろっています」が出れば完了

> 「更新するものがありません」でも異常ではない。今日来た人がまだ誰も予約登録されていないだけ。③へ。

---

## ③ 予約取込Excel作成.bat

1. JSON をドラッグ
2. 質問に答える
   ```
   Date (…):           2026/10/06   ← 今日の日付。数字だけ
   Option columns? [Y]: y           ← そのまま Enter でもよい
   ```
3. 「出す人 : ○人」を確認（＝今日受付したが健診ナビに無い人）
4. デスクトップに `予約取込_日付_時刻.xlsx` と `….確認一覧.txt` ができる

> 同じ名前のファイルが複数できる。**時刻が一番新しいもの**を使う。
> 「出す人 : 0 人」なら全員もう入っている。④は飛ばして⑥へ。

---

## ④ 健診ナビの「予約データ取込」

1. ③の Excel をドロップ
2. 行の「個人マスタ」「予約」を見る
   - `無 / 無` → 「**個人マスタ登録**」を押す → ボタンが「予約登録」に変わる
   - `有 / 無` → そのまま「**予約登録**」
3. 「予約登録中…」の間は「応答なし」と出ても**待つ**（人数×数秒）
4. 終わったら⑤へ

### ボタンが出ないとき
**どこかの行に赤いセルがある。** 右へスクロールして探す。

| 赤い場所 | 原因 | 直し方 |
|---|---|---|
| 事業所名が【福生】でない会社になっている ＋ コースが赤 | 事業所の対応表のコードが間違い | Excel のその行の R列（事業所コード）・S列（事業所名）を正しいものに直して保存 → ドロップし直す。あわせて `form\fussa_company_map.csv` も直す |
| 事業所名は【福生】○○ だが コースが赤 | その団体に FA/FB/FC のコースが無い | 健診ナビで団体にコースを足す（福生市商工会と同じ設定）→ ③からやり直し |
| 生年月日・性別が赤 | 値が空か形式違い | 受付アプリで直して JSON を出し直す |

直せない行は **Excel からその行を削除**して、残りを先に入れる。削除した人は原因を直してから③をもう一度やれば、その人だけの Excel ができる。

## ⑤ 受付結果取込.bat（もう一度）

②と同じ。「更新する人」が④で登録した人数になっていれば Y。

> 数が合わないとき（例: 24人登録したのに 22人）
> → 残りの人が「見つかりません」に出ているか見る。出ていれば④で登録に失敗している。
>   健診ナビの予約画面でその人を検索して、いなければ④をやり直す。

---

## ⑥ ★のお知らせ

⑤の画面の「お知らせ」で ★ が付いたものだけ健診ナビの画面で対応する。

| 表示 | やること |
|---|---|
| ★検査の変更 [胃部=cancel] | 胃部の枠を外す |
| ★検査の変更 [採血=cancel] | 採血の枠を外す（検体依頼からも外れる） |
| ★オプション変更 中止[D.E] | オプションを外す／後日受ける人はそのまま |
| ★カナが違います | どちらが正しいか確認。受付が正しければ bat の代わりに `powershell -File 受付結果取込.ps1 -Json <JSON> -OverwriteKana` |
| ★受診日が違います | 健診ナビの画面で受診日を直してから⑤をもう一度 |
| 生年月日が違います | どちらが正しいか確認して手で直す |

★の無い行（「受付番号は入れました」など）は読むだけでよい。

## 困ったとき

- **「カナが違います」が100件以上出る** → `受付結果取込.ps1` が古い。最新版に上書き
- **「オプションの対応表がありません」** → `form\fussa_option_map.csv` が無い。入れる
- **「JSON プリミティブです: PK」** → Excel をドラッグしている。JSON をドラッグする
- **「見つかりません」が多すぎる** → `form\fussa_company_map.csv` が古い可能性。`ILL CLIPPER` の行が `0000000455` か確認
- **入れたものを戻したい** → `excel_tools\backup\受付結果取込_日付_時刻\取り消し.sql`
