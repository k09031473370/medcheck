# 判定基準の確認メモ（人間ドック学会 ↔ 当院の設定）

作成 2026/09/13　／　きっかけ：2026/08/21 城西学園 88名で 総合判定 F（要精検）が 36名（41%）と多く、
判定基準の設定が妥当か確かめたもの。DBは読むだけで、健診ナビのマスタは一切変更していない。

## 1. 判定区分の対応（文字の読み替え）

学会は4段階、健診ナビ（当院）は8段階。**同じアルファベットでも指すものが違う**ので注意。

| 学会（4段階） | 当院・健診ナビ（8段階） |
|---|---|
| A 異常なし | **A 異常なし** |
| B 軽度異常（日常生活に支障なし） | **B ほぼ正常（心配なし）** |
| | C 要注意 ← 学会にはない |
| C 要経過観察・生活改善 | **D 要観察（要経過観察）** |
| | E 要再検 ← 学会にはない |
| D 要医療（要精密検査・要治療） | **F 要精検** |
| | G 要治療 ← 当院で特に重いときだけ |
| | J 治療中 |

当院には「C 要注意」「E 要再検」が挟まっているため、同じ重さでも文字が後ろにずれる。
学会の「C 要経過観察」に当たるのは当院の **D 要観察（要経過観察）**、
学会の「D 要医療」に当たるのは当院の **F 要精検**。日本語を見れば同じ意味になっている。

**この読み替え自体は重さを変えていない。** 学会Cを当院Cにすると「要注意」という別の意味になってしまうため、
日本語が一致する方に当てているだけ。

## 2. 基準値マスタの前提

- 健診ナビの基準値は `T_KIJUN1`（数値項目）と `T_KIJUN2`（定性項目）に入っている。
- どちらも `KIJUN_CD` で区別され、**1 = 基準値1（学会準拠）／10 = 東振協**。
- **1,067コースすべてが KIJUN_CD = 1** を使っている。東振協の基準値セットは登録されているが使われていない。
- 基準値1の中に、同じ RENBAN を共有する定義が2組ある（学会そのままの C/D1/D2 の組と、当院の D/F/G の組）。
  重複 158件。実際に効いているのは **D/F/G の組**。→ 江東微研に確認したい点。

  仕組み上おかしくはないが、**A が0人**は事業所から見ると目を引くので、聞かれたときの答えを用意しておく。

- 要精検 41% は、上記③②の厳しめ設定と、所見項目の C→D／D→F の読み替えが効いている。

## 6. 残っている不安材料

1. **総合判定 A が0人** — 聞かれたときの説明を用意する。
2. **要精検 36名（41%）** — 再検の実費と手間が受診者・事業所にかかる。上記②③の設定が効いている。
3. **健診ナビのDBと渡した帳票が食い違っている** — 脂質検査は DB が 神杉A／中山B／飛田B のまま、帳票は D／B／D。
   来年の「前回判定」に古い値が出る。→ 後日3名だけ健診ナビのくくり判定で直す（自動判定は不要）。
4. **既往歴と判定の不整合** — 既往歴を取り込んだが自動判定をかけていないので、高血圧・糖尿病の既往がある人でも
   J（治療中）にはなっていない。意図してそうしている（他の判定を崩さないため）。
5. **未受診10名** — 渡すのは88名分。名簿は98名なので、10名が未受診であることを別途伝える。

## 7. 外部（依頼元）への説明について

説明書 `城西学園_結果報告書のご説明_20260821.docx` には
「人間ドック学会の判定区分に**準じて**当院の健診システムに設定された基準値による自動判定」と記載している。
これは事実として正しく、基準値そのものも報告書の基準値欄に印字されている。**外向きはこのままでよい。**

上記③〜⑤は、直すと決まっていない段階で外部文書に書くと説明が増えるだけなので、
**まず院内で医師に報告 → 次回から修正**、の順で進める。
