# 健診結果 取込マニュアル

芝浦健診クリニック / KENSHIN navi 11 — 第3版 2026/07/31

## 1. はじめに

健診の結果をExcelから健診ナビへ自動で登録するツールです。手入力の代わりに使います。

**覚えておくこと**
- 「プレビュー」で内容を確認してから「書込実行」。プレビューだけならデータは変わりません
- 書込む前のデータは自動でバックアップされます(backupフォルダ)
- 書込んだあとは、健診ナビで必ず「自動判定」を実行します

**ファイルを選べば、どちらのレイアウトかはツールが自動で判別します。**(うまく判別されないときだけ「レイアウト」で手動選択)

ツールの場所: `C:\Users\User\Documents\excel_tools`（USBに入れて持ち歩くこともできます）
起動のしかた: そのフォルダの **`start.bat` をダブルクリック**

## 2. データの種類と作業の早見表

| 種類 | ファイルの見た目 | やること |
|---|---|---|
| **リアンパターン** | 氏名・受診日・結果が入った横長のExcel(106列) | 第3章。予約登録から結果取込まで一式 |
| **芝浦巡回AIデータ** | 受付NOと結果だけのExcel(44列)。氏名なし | 第4章。結果の取込だけ |
| **心電図の結果** | 心電計から出るCSV(ecgresult〜) | 第5章 |

**血液検査**: リアンはSRLから届くExcelをこのツールで取り込みます(3-5)。それ以外は従来どおり江東微研から取り込みます。

## 3. リアンパターン の手順

### 3-1. 予約取込ファイルを作る 〈ツール〉

※ 予約取込フォーマットに手入力済みのファイルがある場合は、この手順は飛ばして 3-2 へ。

1. `start.bat` をダブルクリックしてツールを開く
2. 「参照...」で名簿のExcelを選ぶ
3. 「予約取込ファイルを作成」を押す
4. デスクトップに「予約取込_日付.xlsx」ができるので、開いて内容を確認する

### 3-2. 受診者を登録する 〈健診ナビ〉

1. 健診ナビの「予約データ取込」を開く
2. 3-1 で作ったExcel(または手入力済みのファイル)を読み込む
3. 受診者と検査項目の枠が作られる

### 3-3. 受付番号を入れる 〈ツール〉

当日発行した受付番号を、氏名で照合して健診ナビへ一括で入れます。手入力は不要です。

1. ツールの「参照...」で当日の結果Excelを選ぶ(レイアウトは自動で判別されます)
2. 「受付番号を設定」を押す → 一覧を確認 → 「はい」で設定

※ すでに受付番号が入っている人は「設定済み(変更なし)」と出てそのままです。

### 3-4. 結果を取り込む 〈ツール〉

1. 同じファイルのまま、受付番号を入れる(空欄なら全員)
2. **「受診日」は空欄のままにする**(リアンのExcelには日付の列があるので、そこから読みます)
3. 「3. プレビュー」を押す
4. 「状態」の列がすべて OK になっていることを確認する
5. 「4. 書込実行」→ 確認の画面で「はい」

### 「受診日」欄について

- **空欄**にしておくと、Excelの日付の列から自動で読みます(リアンはこちら)
- **入力**すると、Excelの日付より入力した日付が優先されます。その場合は確認の画面が出るので、内容を見て「はい」か「いいえ」を選んでください
- 日付の列が無いファイル(芝浦巡回AIデータ)では入力が必須です(確認の画面は出ません)
- 書き方は `2026/07/12`。`260712` や `20260712` でも通ります

### 3-5. 血液を取り込む 〈ツール〉

SRLから届くExcel(パスワード付き)を使います。**他社の受診者も混ざっている**ので、名簿でしぼり込みます。

1. 「参照...」でSRLのExcelを選ぶ(パスワードは自動で解除されます)
2. **「名簿を選ぶ」でリアンのExcel(結果が入っているもの)を指定する** ← これをしないと他社の人まで対象になります
3. 「受診日」は空欄でOK(SRLのファイルに受診日が入っています)
4. 「3. プレビュー」→ 状態がすべて OK か確認
5. 「4. 書込実行」

名簿に無い人は `[名簿しぼり込み] 名簿に無い ○ 人は取り込みませんでした` と出ます。これは正常です。

**入る項目**: クレアチニン / 尿酸 / 総コレステロール / LDL / HDL / 中性脂肪 / AST / ALT / ALP / γ-GTP / 血糖 / HbA1c / 白血球 / 赤血球 / 血色素 / ヘマトクリット / 血小板 / eGFR / MCV / MCH / MCHC / 便潜血1回目・2回目

### 3-5b. 心電図について

心電図は結果取込(3-4)で一緒に入ります。**別の操作は要りません。**

- リアンのExcelの **心電図・所見(101列)** に書いてある人 → そのまま所見が入ります
- 所見が空の人 → **「正常範囲」が自動で入ります**

自動で入れてよいと判断した理由: 過去47日分・約340人を調べたところ、心電図の枠がある人には全員所見が入っていました（`check7.bat` で確認）。つまり枠がある人は必ず撮っている、ということです。

**もし「枠はあるが撮らなかった人」が出たら**、その人だけ健診ナビの画面で心電図の欄を空に戻してください。取込前に気付いたときは、プレビューの「状態」に **OK(既定値)** と出ている人が自動で入る人なので、そこで確認できます。

心電計から出るCSVで入れることもできます（第5章）。撮った人しかCSVに出てこないので、より確実です。

### 3-5c. 社員番号について

結果取込(3-4)のときに、Excelの1列目の**社員番号が個人マスタへ自動で入ります。**別の操作は要りません。

- 空欄の人 → 入ります
- すでに同じ番号が入っている人 → そのまま（「設定済み(変更なし)」と出ます）
- **すでに違う番号が入っている人 → 入れません**（「取込対象外(すでに別の番号 ○○ が入っています)」と出ます）

3番目は、勝手に上書きすると過去の結果票にも影響が出るためです。番号が変わったのなら、健診ナビの個人マスタ画面で直してください。

**事業所名は元から入っています。**予約取込のときに事業所コードが入るので、結果票にはそのまま出ます。

※ 社員番号を結果票に印字するには、帳票テンプレートに差込み文字 `**社員番号` を足す必要があります。まだ足していません（担当者に相談してください）。

### 3-6. 自動判定 〈健診ナビ〉

**結果も血液も入れ終わってから**実行します。先に実行すると血液抜きの判定になります。

1. 健診ナビで対象者を開き、値が入っていることを目で確認する
2. 「自動判定」を実行する(BMI・標準体重・判定はここで計算されます)
3. 東振協などの提出データを出力する

## 4. 芝浦巡回AIデータ の手順

このExcelには氏名も受診日も入っていません。**予約登録と受付番号の入力が済んでいることが前提**です。

### 4-1. 結果を取り込む

1. `start.bat` でツールを開く
2. 「参照...」でそのExcelを選ぶ(レイアウトは自動で判別されます)
3. **「受診日」に実施日を入力する**(例 2026/05/21) ← 日付の列が無いので必須
4. 受付番号は空欄のまま(全員が対象)
5. 「3. プレビュー」→ 状態がすべて OK なら「4. 書込実行」
6. 健診ナビで「自動判定」を実行する

**「受診者が見つかりません」と出たら**: その受付番号が健診ナビにまだ入っていません。下の 4-2 で入れてから、もう一度実行してください。

### 4-2. 受付番号が入っていないとき

芝浦巡回AIデータには氏名が無いので、そのファイルだけでは誰が何番か分かりません。**氏名と受付番号の一覧**を作って、ツールに入れさせます。

1. ツールのフォルダにある **`受付番号リスト_ひな形.xlsx`** をデスクトップにコピーする
2. 開いて、2行目から **受付番号・氏名**(フリガナは任意)を入力して保存する
3. ツールの「参照...」でそのファイルを選ぶ(レイアウトは自動で判別されます)
4. **「受診日」に実施日を入力する**(例 2026/05/21) ← このファイルには日付の列が無いので必須
5. 「受付番号を設定」を押す → 一覧を確認 → 「はい」

そのあと 4-1 に戻って、AIデータの取込をやり直してください。

※ 数人だけなら、健診ナビの受診者の画面で受付番号を直接入力しても構いません。

**「該当者なし」と出たら**: その氏名がその受診日で健診ナビに登録されていません。受診日と氏名の表記(スペース・旧字体)を確認してください。

## 5. 心電図の結果を取り込む

心電計から出るCSVを使います。ID列がその日の受付番号、検査日列が受診日として扱われます。

**`心電図取込.bat` にCSVをドラッグ＆ドロップ**してください。プレビューが出て、確認してから `y` を押すと書き込まれます。

（ダブルクリックしてからパスを貼り付けても同じです）

- 所見が無く判定Aの人には「正常範囲」が自動で入ります
- 判定(A・B・C12など)も一緒に登録されます
- 1人だけにしたいときは `-Only 13` のようにIDを付けます

## 6. 困ったときは

| 画面に出る言葉 | 意味 | どうするか |
|---|---|---|
| 枠なし | その人のコースにその検査が無い | 対象外の検査なら、そのままで問題ありません |
| 受診者が見つかりません | 受付番号か受診日が健診ナビと合っていない | 受診日と受付番号を確認する |
| 名簿でしぼり込んだ結果、対象が0人 | 名簿と取込ファイルの受診日が違う | 画面に出る日付を見て、受診日欄に名簿と同じ日付を入れる |
| 氏名が一致しません | Excelの氏名と健診ナビの氏名が違う。受付番号が別人に付いている可能性 | **受付番号を確認する。**別人に書き込まないよう、その人は飛ばされます |
| 結果入力画面で編集中 | その人の画面が健診ナビで開いている | 健診ナビでその人の画面を閉じて、もう一度実行 |
| 変換表に無いコード | Excelの値がまだ登録されていない | 担当者に連絡(対応表の追加が必要) |
| 取込対象外(変換表で除外: 160) | 健診ナビ側に同じ意味の選択肢が無い値。自覚症状の一部(鼻づまり・視力低下・下痢や便秘・胃やお腹が痛む・かゆみ・物忘れ)が該当 | そのままで問題ありません。必要なら健診ナビの画面で手入力してください |
| 取込対象外(同じ内容が自覚症状1に入るため) | Excelに違う言い方で書かれた2つが、健診ナビでは同じ選択肢になる | そのままで問題ありません |
| 所見CD未登録 | 所見のコードが健診ナビに無い | 担当者に連絡 |
| 接続エラー | サーバーに繋がっていない | VPN・ネットワークを確認。それでも駄目なら担当者へ |

エラーが出た人は書き込まれません。他の人の処理は続きます。

## 7. やってはいけないこと

- **プレビューを見ないで「書込実行」を押さない**
- 取込む人の結果入力画面を健診ナビで開いたままにしない(書いた内容が消えます)
- 「エラーを飛ばす」「氏名の違いを無視する」のチェックは、理由が分かっているとき以外は使わない
- form フォルダの中のCSVをExcelで編集しない(先頭の 0 が消えて壊れます)
- 江東微研のコード変換マスタ、検査センター.csv は変更しない

## 8. 元に戻したいとき

書込むたびに、その人の書込前のデータが `backup` フォルダにCSVで保存されています。

- `T_KENSA_〜.csv` … 検査結果
- `T_KOJIN1_〜.csv` … 個人マスタ（社員番号を入れたとき）

どちらも `元に戻す.bat` で戻せます。

**1〜2項目だけ**なら、健診ナビの画面から手で直すのが一番早いです。

**まとめて戻したいとき**は **`元に戻す.bat` をダブルクリック**してください。

1. バックアップの一覧が出ます
2. 戻したいファイル名をコピーして貼り付ける
3. 何が戻るかが表示されます（まだ戻りません）
4. `y` を押すと戻ります

戻す前の状態も保存されるので、やり直せます。

戻したあとは健診ナビで **自動判定をやり直してください**。

判断に迷うときは担当者に相談してください。

## 付録: ボタンの意味

| ボタン | 何をするか |
|---|---|
| 参照... | 取り込むExcelやCSVを選ぶ |
| 1. 列確認 | Excelの何列目が何の項目かを表示する(確認用・データは変わらない) |
| 2. 枠一覧(DB) | その人の検査項目の一覧を健診ナビから読んで表示する(確認用) |
| 受付番号を設定 | 氏名で照合して、受付番号を健診ナビに入れる |
| 予約取込ファイルを作成 | 名簿から、健診ナビの予約データ取込で読ませるExcelを作る |
| 3. プレビュー | 何がどう書き込まれるかを表示する(データは変わらない) |
| 4. 書込実行 | 実際に健診ナビへ書き込む |
| 名簿でしぼり込む | 名簿(リアン等)を指定すると、その名簿に載っている人だけを取り込む。空欄ならファイル内の全員 |
| 氏名の違いを無視する | 通常はチェックしない。Excelと健診ナビで氏名が違う人を、あえて取り込むときだけ使う |

## 付録: 同梱ファイル

| ファイル | 何に使うか |
|---|---|
| `受付番号リスト_ひな形.xlsx` | 氏名と受付番号だけの一覧。芝浦巡回など、結果ファイルに氏名が無いときに受付番号を入れるために使う |
| `予約取込フォーマット.xlsx` | 「予約取込ファイルを作成」で使うテンプレート。健診ナビからもらった原本をこの名前で置く |
| `心電図取込.bat` | 心電図CSVの取込。CSVをドラッグ＆ドロップ(第5章) |
| `元に戻す.bat` | 書込前のバックアップから元に戻す(第8章) |
| `USBで使うときは.txt` | USBに入れて使うときの注意 |
