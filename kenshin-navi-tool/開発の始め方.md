# 自分のPCで開発を始める

いまの仕組みをそのまま土台にして、自分のPCで改良していくための手順です。

---

## なぜ健診ナビのDBをそのまま使うのか

作り直さないほうがいいものが、DBの中に大量に入っています。

| 中身 | 例 |
|---|---|
| **基準値** | `T_KIJUN1`。項目ごと・性別ごとの正常範囲と判定記号 |
| **判定ロジックの材料** | `T_KOMOKU`(項目) / `T_SYOKEN2`(選択肢・所見 94リスト) |
| **所見コード表** | `ZK021` は217種。**東振協のコード表そのもの**だった |
| **コースと料金** | `T_COURSE1〜4` / `M_OPTION` / `M_DANTAI` |
| **過去の受診データ** | `T_KENSA` 76万行 |

これは何年もかけて積み上がった設定です。**ゼロから作ると、ここで必ず行き詰まります。**

だから方針はこうします。

```
   健診ナビ        ← 帳票・法定提出・マスタ管理はこのまま使う
        ＼
         [ 同じ SQL Server DB ]   ← 基準値・所見マスタ・過去データはここ
        ／
   自作の画面       ← 使いにくいところだけ置き換えていく
```

両方が同じDBを見るので、**自作画面で入れたものが健診ナビの結果票にそのまま出ます。**
どちらか一方に寄せる必要はありません。

## 手順

### ① ソースを自分のPCに置く

`medcheck.bundle` から、履歴ごと復元できます。

```
git clone medcheck.bundle medcheck
cd medcheck\kenshin-navi-tool
```

以降、変更するたびに `git commit` しておけば、いつでも戻せます。

### ② DBを用意する（`テスト用PCの作り方.md` 参照）

1. `C:\HIT\K166_SIBAURAUSER.bak` をUSBでコピー
2. SQL Server Express に復元
3. **`mask_testdb.ps1` で仮名化**（氏名などを架空の値にする）
4. USBの `.bak` を消す

### ③ 接続先を自分のPCに向ける

`kenshin-navi-tool` フォルダに **`接続先.txt`** という名前でファイルを作り、1行だけ書きます。

```
Data Source=localhost\SQLEXPRESS;Initial Catalog=K166_SIBAURAUSER;Integrated Security=True
```

これだけで**全部のツールが自分のPCのDBを見るようになります。**
`start.bat` も `請求一覧.bat` も `健診ビューア.bat` も、一切書き換え不要です。

**このファイルは配布zipには入りません。**開発PCにだけ置くので、本番の設定を汚しません。

#### 取り違え防止

`接続先.txt` を使っているときは、画面に**紫色で**こう出ます。

```
[開発用の接続先を使っています] 接続先.txt
[DB] 接続先: Data Source=localhost\SQLEXPRESS;...
```

本番PCではこの行は出ません。**書込の前にこの色を見る習慣**をつけてください。

### ④ 動かしてみる

```
健診ビューア.bat     ← ブラウザで受診者一覧が開く(読むだけ)
start.bat            ← 取込ツール
請求一覧.bat         ← 請求明細
```

壊しても、②をやり直せば元通りです。**遠慮なく試せます。**

## 改良の進め方

### 自作画面（`kensin_web.ps1`）を育てる

いまは受診者一覧と個人の検査一覧だけです。ここに画面を足していきます。

構造はこうなっています。

```
kensin_web.ps1
  Render-List    … 受診者一覧の画面を作る
  Render-Person  … 個人の画面を作る
  (ルーティング) … /list /person …
```

**画面を1つ足す = 関数を1つ書いて、ルーティングに1行足す**だけです。

### 取込・請求は対応表で足りることが多い

新しいレイアウトのExcelが来ても、多くは `form\mapping_*.csv` に行を足すだけで済みます。
料金やオプションも `seikyu_prices.csv` / `seikyu_rules.csv` に行を足すだけです。
**プログラムを直さずに済む形**にしてあります。

### 出来たものを本番へ

`make_zip.py` を実行すると `excel_tools.zip` が出来ます。
これを事務員PCのフォルダに上書き展開すれば反映されます。

```
python make_zip.py
```

`接続先.txt` は zip に入らないので、本番が自分のPCを見に行くことはありません。

## やらないほうがいいこと

- **健診ナビの帳票・法定提出を自作で置き換えようとする**
  東振協・協会けんぽ・特定健診XMLは仕様が細かく、変更も入ります。ここは健診ナビに任せる
- **マスタ（項目・所見・基準値・コース）を自作画面から書き換える**
  健診ナビ側の整合が崩れます。マスタの編集は健診ナビの画面で
- **本番DBで試す**
  自分のPCのコピーで試してから持っていく
